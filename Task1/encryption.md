# Данные для защиты и методы обеспечения безопасности
### Персональные данные пациентов
* ФИО, дата рождения, паспортные данные, адрес, телефон, e-mail
* Методы защиты:
  * Шифрование при хранении (в БД, файловом сервере).
  * Шифрование при передаче (TLS, СКЗИ).
  * Обезличивание (при аналитике и отчетах для руководства).
  * Обфускация (маскирование паспортных данных в интерфейсах).

### Медицинские данные
* Диагнозы, результаты анализов, назначения, сканы медицинских документов
* Методы защиты:
  * Шифрование при хранении (ФСБ-сертифицированное для ПДн мед. категории).
  * Шифрование каналов передачи (VPN, TLS).
  * Обезличивание (например, при передаче данных в лаборатории для исследований).
  * Контроль доступа (RBAC: врач видит только свои записи).

### Финансовые данные пациентов
* Информация об оплатах, реквизиты, чеки, данные кассы/терминала
* Методы защиты:
  * Шифрование при хранении (особенно реквизиты).
  * Маскирование в отчетах (например, только последние цифры карты).
  * Обезличивание (для статистики).
  * Разграничение доступа (бухгалтерия ≠ врач ≠ регистратура).

### Данные сотрудников
* ФИО, должность, контакты, учетные записи, доступы
* Методы защиты:
  * Шифрование учетных записей (пароли только в хэшированном виде).
  * Журналирование действий (аудит).
  * Обфускация в отчетах (скрытие лишних полей).

### Управленческая отчетность
* Агрегированные отчеты о пациентах, услугах, оплатах
* Методы защиты:
  * Обезличивание (удаление ФИО, замена на ID).
  * Шифрование каналов передачи (когда отчеты уходят руководству).
  * Обфускация чувствительных полей (например, скрыть паспорт).

### Служебная переписка (Outlook)
* E-mail с вложениями: направления, результаты анализов, отчеты
* Методы защиты:
  * Шифрование почтового трафика (TLS, S/MIME).
  * DLP-система для контроля отправки наружу.
  * Автоматическая очистка вложений от ПДн перед пересылкой наружу.
