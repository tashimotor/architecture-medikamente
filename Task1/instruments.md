#  Cписок инструментов, способов и мер, которые позволят обеспечить конфиденциальность данных

### Передача данных между участниками (пациент, регистратура, врачи)
* TLS 1.3 / HTTPS — все API и внутренние интерфейсы должны работать только по защищенным каналам.
* mTLS (внутренние сервисы) — двусторонняя аутентификация между подсистемами.
* VPN / Zero Trust Network — изоляция доступа к медсистеме.

### Хранение персональных и медицинских данных
* Шифрование на уровне БД:
  * PostgreSQL TDE (Transparent Data Encryption) или pgcrypto.
  * В MySQL — InnoDB Encryption.
* Шифрование на уровне файлового хранилища (например, S3-compatible storage с включённым SSE).
* Разделение БД по тэгам (PII отдельно от обезличенных данных).

### Доступ сотрудников (регистратура, врачи, бухгалтерия)
* RBAC (Role-Based Access Control) — доступ только по ролям.
* MFA (многофакторная аутентификация) для всех сотрудников с доступом к конфиденциальным данным.
* Журналирование (audit trail) — запись всех операций доступа к карточке пациента.

### Работа с отчетностью
* Автоматическая анонимизация при выгрузке отчетов.
* Агрегация данных для руководства без доступа к исходным персональным данным.

### Взаимодействие с финансовым отделом
* PCI DSS практики (если есть платежные реквизиты).
* Шифрование банковских данных в транзакциях (например, AES-256).
* Маскирование реквизитов карт(например, ****1234).

### Организационные меры
* Регламент хранения и удаления (сроки по 152-ФЗ: не дольше, чем нужно для цели).
* Обучение сотрудников правилам работы с ПДн.
* Регулярные аудиты (внутренние и внешние).
* DLP-система (контроль утечек по почте, флешкам, мессенджерам).
